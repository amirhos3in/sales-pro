# نکس‌سل

پروتوتایپ آکادمی تخصصی مهارت‌های فروش. چهار مسیر آموزشی (حضوری، مذاکره، تلفنی، آنلاین)، سه پلن اشتراک، کیف پول آزمایشی، پیشرفت درس‌ها و پشتیبانی انسانی به‌همراه دستیار تمرین جمله.

داده‌ها فقط در مرورگر ذخیره می‌شوند. پرداخت و پاسخ پشتیبان شبیه‌سازی شده است.

## اجرا

```bash
npm install
npm run dev -- -p 43123
```

سپس در مرورگر [http://127.0.0.1:43123](http://127.0.0.1:43123) را باز کنید.

نسخهٔ عمومی: [https://amirhos3in.github.io/sales-pro/](https://amirhos3in.github.io/sales-pro/)

برای ساخت همان خروجی ثابت:

```bash
npm run export:pages
```

ورود با موبایل و کد آزمایشی است. نام و نام خانوادگی و شماره موبایل لازم است؛ هر کد ۴ تا ۶ رقمی، مثلاً `1234`، قبول می‌شود. مسیرهای تخصصی با پلن طلایی یا VIP باز می‌شوند و هر درس بعد از تایید تماشا یک چالش سه‌سؤالی دارد. آموزش رایگان فقط ورود می‌خواهد و ویدیوها به ترتیب چالش باز می‌شوند.
